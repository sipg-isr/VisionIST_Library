# The MediaPipe Tasks API. Pinned: the 0.10 -> 1.x step changed the package
# layout (the legacy `mediapipe.solutions` graphs are gone), so an unpinned
# install is not a no-op for this service.
mediapipe==1.1.0
# cv2 is NOT listed here on purpose. mediapipe requires opencv-contrib-python,
# and installing opencv-python-headless alongside it puts two builds of the
# same module in the image, with whichever landed last winning. The service
# imports cv2 from mediapipe's dependency; libgl1 in the Dockerfile is what
# that build needs at runtime.
#
# What IS listed is an upper bound on that same distribution - mediapipe
# declares `opencv-contrib-python` with no bound at all, so an unpinned
# rebuild lands on OpenCV 5 (released 2026-01). Constraining the version is
# not the same as adding a second cv2 build: this is the package mediapipe
# already pulls, just bounded.
opencv-contrib-python>=4.10,<5
